## 排除原因与偏差

| 原因 | 记录内自车轨迹/窗口数量 |
| --- | ---: |
| 非乘用车 | 452 |
| 连续有效主线轨迹不足 20 秒 | 190 |
| 自车超出等宽直道近似边界 | 1418 |
| 自车位置差分异常 | 11 |
| 窗口内背景位置跳变 | 1511 |
| 起点自车与背景车重叠 | 38 |

以上按程序的排除顺序计数，原因互斥；不代表一条轨迹只可能有一个问题。没有发现同车同时间的冲突轨迹。正式回放生成时没有额外拒绝窗口。

**限制：** 直道几何近似排除了一部分实测主线轨迹；任一背景车跳变导致整窗排除的规则较保守，尤其影响早期 I-80 训练记录。20 秒长度、几何近似与质量门槛均应在论文中公开，并做敏感性分析。片段按事件抽样且共享交通，不代表自然交通风险分布或相互独立样本。
