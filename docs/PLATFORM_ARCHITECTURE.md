# Unified research platform architecture

The repository now separates the existing single-ego SafeRL task from the two-actor SR-AIRL task. `rl.algorithms.REGISTRY` remains the four-algorithm SafeRL registry. `tasks.registry.TASK_REGISTRY` is an independent top-level task catalog, and the Studio API exposes each task's readiness state.

`env.safe_metadrive_env.SafeMetaDriveEnv` remains the compatibility import; its implementation now lives at `env.tasks.safe_rl_env` and is also named `SafeRLEnv`. `InteractionScenario` provides explicit role IDs and road/data metadata. `RecordedTrafficManager` accepts controlled track IDs, and `InteractionTrafficManager` excludes two or more declared interaction actors from replay. Formal procedural Highway scenes are straight (training), curve and merge (transfer); intersection, T-junction and roundabout remain auxiliary. The base experiment configuration now defaults to `map="S"`.

`SRAIRLEnv` implements the checked 0.1-second legacy kinematic state transition and independent joint SR-AIRL observation interface. `ExpertDatasetBuilder` builds role-separated transitions outside the environment. `SocialAIRLDiscrim`, the anisotropic shared interaction potential, two PPO policies and alternating `SRAIRLTrainer` are available for legacy-kinematic training. The CLI consumes a JSON manifest; Studio dispatches the same trainer/evaluator from an imported NGSIM clip with explicit ELCV/RFV/current-leader/target-leader IDs. Studio writes training checkpoints under `models/<job-id>/`, evaluation curves under `results/<job-id>/`, and renders the MetaDrive NGSIM road with role-colored ELCV/RFV and replay actors. In legacy mode, both policy actions update the canonical kinematic states, which synchronize to the corresponding MetaDrive vehicle bodies after each world step.

This remains a partial research integration, not a verified MetaDrive reproduction. The public upstream repository lacks its original `reward_config.py` (the study supplied the constants now used here), imported clips have no verified automatic SR-AIRL role mapping, canonical importer derivatives differ from upstream preprocessing, and no original expert pickle is present for numeric parity checks. The Studio flow therefore requires role IDs to be selected manually and labels its dynamics as legacy kinematics. Recorded background actors can use an optional bounded IDM-like response to a policy vehicle approaching in the same lane; this is an interaction baseline, not calibrated or validated human-driver behavior. The calibrated MetaDrive-vehicle-physics action bridge, upstream diffusion planner/reward guide/future predictor training chain and complete seven-page Studio information architecture remain unimplemented. See `rl/srairl/UPSTREAM.md` for source details and limitations.
